# PRISMA ARENA — Téléchargements

Combat élémentaire en arène 3D, en ligne (1v1) : Feu, Eau, Terre, Vent.

**Télécharger :** ouvre l'onglet [Releases](../../releases/latest) et prends `PRISMA-ARENA-Setup-x.y.z.exe` (Windows 10/11, 64 bits).

Le launcher se met ensuite à jour tout seul.

> Windows peut afficher « Windows a protégé votre ordinateur » : clique sur **Informations complémentaires**, puis **Exécuter quand même**.

Ce dépôt ne contient que les installeurs publiés.
